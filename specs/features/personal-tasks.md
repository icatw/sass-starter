# 示例功能：个人任务清单

## 目标

以可删除的个人任务清单作为模板示例，验证认证用户数据归属及规格 → 迁移 → Go API → OpenAPI Client → Next.js UI 的垂直开发流程。

## 范围

### 包含

- 登录用户列出自己最近更新的最多 100 条任务。
- 创建任务、标记完成/未完成、删除任务。
- 标题长度为 1–200 个字符；保存前去除首尾空格。
- 任务在账号间隔离，不实现共享、组织、标签、截止日期、搜索或分页。

### 不包含

- 多租户、组织、协作、通知、后台队列、计费和部署改造。
- 管理员跨用户读取或管理任务。

## 领域规则

- 每条任务始终关联创建者 `user_id`；所有读取和变更查询同时限定任务 ID 与当前用户 ID。
- 客户端不可提交或修改 `user_id`。
- 空标题或超过 200 字符返回 400；无效/缺失身份返回 401；访问他人任务与不存在的任务统一返回 404。
- 列表按 `updated_at DESC, id DESC` 排序并最多返回 100 条。

## API 契约

- `GET /v1/tasks` → `{ tasks: Task[] }`
- `POST /v1/tasks`，请求 `{ title }` → 201 `{ task: Task }`
- `PATCH /v1/tasks/{taskId}`，请求 `{ completed }` → `{ task: Task }`
- `DELETE /v1/tasks/{taskId}` → 204
- `Task` 字段：`id`、`title`、`completed`、`createdAt`、`updatedAt`。
- API 均需内部 Bearer JWT；写操作还需通过现有同源 Origin 校验。

## 验收条件

- [x] 用户可创建、列出、完成/恢复和删除自己的任务。
- [x] 用户 A 无法通过更新或删除 API 操作用户 B 的任务；响应统一为 404。
- [x] 客户端伪造 `userId` 不改变任务归属。
- [ ] 空标题、超长标题和无效任务状态被拒绝（空白标题已验证；超长与状态类型边界待补行为测试）。
- [x] Web 覆盖加载、空列表、API 错误和提交中状态。
- [x] 契约生成、Go 行为测试与认证集成 smoke 覆盖主要权限路径。
- [ ] 删除示例代码和迁移之外的业务模块后，认证、用户目录、OpenAPI 生成和基础 Harness 仍可运行。

## 验证命令

```bash
make db-migrate
make test
make verify
make auth-smoke
```

## 风险与回滚

- 任务属于个人数据，任何查询或更新遗漏 `user_id` 条件都会造成越权；须以跨用户测试覆盖。
- 迁移采用新增序号迁移；回滚前确认没有需要保留的示例任务数据。
