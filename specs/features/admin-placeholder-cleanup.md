## 目标

清理管理后台未实现入口的误导性表达，让导航、搜索和占位页清楚区分：可用、演示数据、尚未实现。

## 范围

### 包含

- 为导航项增加 `available | demo | planned` 状态，并在侧边栏、命令搜索和占位页展示。
- 修正占位页文案，明确“尚未实现”，不再写成“框架已搭好，直接放 UI”。
- 去掉侧边栏假用量组件，避免暗示已有真实计费用量。
- 合并重复入口：`/organizations`、`/admin/orders`、`/admin/subscriptions` 重定向到规范路径。
- 概览页演示横幅改为可本地化文案。

### 不包含

- 实现计费、组织、文件、任务、设置等业务能力。
- 删除演示概览页本身。
- 从导航中隐藏未实现模块。

## 验收条件

- [x] 用户、审计日志显示为可用；概览显示为演示；其余占位模块显示为未实现。
- [x] 占位页文案明确“尚未实现”，并列出仍待实现项。
- [x] 侧边栏不再展示假用量进度。
- [x] 重复路由会重定向到规范页面。
- [x] `make verify` 通过。

## 验证命令

```bash
make verify
```
