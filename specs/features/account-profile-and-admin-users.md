# 个人资料与管理员用户目录

## 目标

完成认证后的基础用户自助资料维护，并为管理员提供只读的用户目录。权限与用户当前状态由 Better Auth Session 和 Go API 分别在其信任边界内校验。

## 范围

### 包含

- 普通用户查看自己的姓名、邮箱和邮箱验证状态。
- 普通用户通过 Better Auth 更新自己的姓名；邮箱和角色不在本功能中修改。
- 管理员通过 Go API 查看最近注册的用户及其角色、邮箱验证、禁用状态和创建时间。
- Go API 固定返回最近 100 个用户；本切片不支持搜索、分页或账号状态修改。
- 页面提供真实数据、空状态和服务错误状态。

### 不包含

- 邀请、模拟登录、角色管理、封禁/解封、Session 撤销。
- 多租户、组织与成员管理。
- 账户删除、邮箱变更和完整审计日志。

## 领域规则

- 用户资料更新只接受姓名；邮箱、角色、禁用状态和用户 ID 不可由请求体修改。
- 管理员目录只允许通过短时内部 JWT 访问；Go 按 token `sub` 查询数据库中的当前角色并要求 `admin`。
- 管理员目录仅返回必要字段，不暴露密码、账户凭据、Session、IP 地址或 User-Agent。
- 普通用户访问管理员 API 返回 403；缺少或无效凭据返回 401。

## API 契约

- 方法和路径：`GET /v1/admin/users`
- 请求：无参数，返回最近 100 个用户。
- 响应：`{ users: [{ id, name, email, role, emailVerified, disabled, createdAt }] }`
- 错误码：401 `UNAUTHENTICATED`、403 `FORBIDDEN`、500 `INTERNAL_ERROR`。
- 个人资料使用 Better Auth `POST /api/auth/update-user`，仅提交 `name`。

## 验收条件

- [ ] 普通用户可更新自己的姓名并在重新加载后看到更新结果。
- [ ] 资料更新拒绝空白姓名，且不会改变邮箱、角色或账号状态。
- [ ] 管理员用户目录显示真实 Go API 数据和验证/禁用状态。
- [ ] 普通用户不能读取管理员目录；伪造角色或用户 ID 不能提升权限。
- [ ] 空用户列表与 API 故障有清楚的界面状态。
- [ ] 中英文 UI 文案齐全。

## 验证命令

```bash
make test
make verify
make auth-smoke
```

## 风险与回滚

- 用户目录包含邮箱等个人信息，仅管理员可访问；不得添加未授权缓存或公开路由。
- 本功能不更改认证数据库结构；若后续新增字段或用户操作能力，使用新迁移并扩展权限与审计规格。
